# Demo Video Script (60 seconds)

Record your screen with the terminal and browser side by side.
Read the timestamps as a guide; keep it under one minute.

| Time  | Action |
|-------|--------|
| 0:00-0:05 | Terminal: `cd backend && npm start`. Show "Research Opportunity Portal running at http://localhost:3000". |
| 0:05-0:15 | Browser: open http://localhost:3000. Fill the "Post a New Research Opportunity" form and submit. Show the green success message and the new card in the list. |
| 0:15-0:25 | Click the new card. Detail view opens. Click Edit, change positions, Save. Show the updated detail. |
| 0:25-0:32 | In the detail view, click Close. Confirm. Status badge changes to Closed. |
| 0:32-0:40 | Click Delete on another card. Confirm. It disappears from the list. |
| 0:40-0:48 | Submit the create form with the title empty. Show the red validation error message. |
| 0:48-0:58 | Postman: run "Get All Opportunities" and "Get Deleted Opportunity (expect 404)". Show 200 with the list, then 404. |
| 0:58-1:00 | Done. |

Tip: do one rehearsal run first so the timing feels natural, then record.
